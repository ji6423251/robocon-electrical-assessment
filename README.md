# RoboCon Electrical Assessment

## Hardware

- RoboMaster Development Board C
- MCU: STM32F407IGH6
- LED_BLUE: PH10
- KEY: PA0, active low

## Development Environment

- STM32CubeMX
- CMake
- GCC for ARM
- OpenOCD
- ST-Link

## Progress

- [x] GPIO LED blink
- [x] Key input controls LED
- [ ] Buzzer
- [ ] PWM LED task
- [ ] Servo
- [ ] UART communication
- [ ] Motor PID control
